# Evidence Review Instructions

You are reviewing blinded evidence packets. Use only the material in your
assigned Markdown file.

## Your Task

For each packet:

- read the parent evidence;
- assess any proposed assessment material, if present;
- decide whether the best-supported handling is resolve, partially resolve, or
  escalate / abstain;
- complete every checkbox and free-text response field.

## Important Rules

- Do not use outside knowledge or search engines.
- Do not try to infer study condition or packet type.
- Do not edit packet IDs, reviewer ID, headings, or checkbox labels.
- Do not discuss your packet with other reviewers until the trial is closed.
- If the evidence is insufficient, choose escalation or abstention and explain
  why.

## Returning Your Response

Return your completed file using this naming pattern:

```text
reviewer_R##_completed.md
```

For example, if your file says `Reviewer ID: R01`, return:

```text
reviewer_R01_completed.md
```
