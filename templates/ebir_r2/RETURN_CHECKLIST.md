# Evidence Review Return Checklist

Return only:

- completed reviewer Markdown files named `reviewer_R##_completed.md`;
- optional timing notes, if collected separately;
- confirmation that reviewers did not access admin files.

Do not return reviewer-facing packets mixed with:

- assignment manifests;
- condition mappings;
- gold labels;
- truthset files;
- admin-only scoring reports.

Before returning responses, verify:

- every packet section has one selected handling option;
- every packet section has one selected quality score;
- every packet section has one selected confidence score;
- free-text fields are no longer placeholders;
- packet IDs and reviewer IDs were not edited.
